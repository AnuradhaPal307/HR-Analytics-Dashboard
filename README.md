# HR Analytics Dashboard

## Project Overview
This project presents an HR Analytics Dashboard built using Microsoft Excel. The dashboard analyzes employee data to provide insights into workforce distribution, employee attrition, and compensation.

## Objective
The objective of this project is to analyze HR data and create an interactive and easy-to-understand dashboard for identifying key workforce trends and insights.

## Dataset
The dataset contains 2,000 employee records with the following key attributes:

- Employee ID
- Department
- Gender
- Job Role
- Education
- Age
- Salary
- Bonus
- Attrition
- Total Compensation

## Data Cleaning
The following data cleaning steps were performed:

- Checked for duplicate Employee IDs.
- Identified and handled missing values in Department, Gender, Salary, Attrition, and Total Compensation.
- Standardized inconsistent department values.
- Treated invalid salary values such as zero or missing values.
- Prepared the cleaned dataset for analysis.

## Key Performance Indicators

The dashboard includes:

- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary
- Average Bonus
- Average Total Compensation

## Analysis Performed

The following analyses were performed using Pivot Tables:

- Department-wise Employee Count
- Department-wise Attrition Analysis
- Gender Distribution
- Job Role-wise Employee Count
- Education-wise Employee Count

## Dashboard Features

The Excel dashboard includes:

- KPI Cards
- Pivot Tables
- Pivot Charts
- Employee Distribution Analysis
- Attrition Analysis
- Compensation Insights
